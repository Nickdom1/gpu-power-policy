# Prior art and related work

As of 2026-10-24. Dates are first public appearance. Links go to the projects' main pages; mVolt+, px13-linux-power and the forum posts were seen through search results and are not linked. This project credits the following; please open an issue if something is missing or wrong.

| Project | What it does | Platform | Relation |
|---|---|---|---|
| **@pantsoftime, `vbios_override` patch** (overclock.net; date unknown) | Credited by Panchovix as the origin of loading a modified VBIOS without flashing | — | Earlier than all of the below |
| **Panchovix: [nvidia-vbios-vix-editor](https://github.com/Panchovix/nvidia-vbios-vix-editor), [nvidia-linux-vbios-vix-loader](https://github.com/Panchovix/nvidia-linux-vbios-vix-loader), [nvidia-windows-vbios-vix-loader](https://github.com/Panchovix/nvidia-windows-vbios-vix-loader)** (2026-10-14 to 10-17) | Offline VBIOS editor (power-policy table, clocks, fans) and loaders that hand the edited image to the driver: a patched open module on Linux (driver 615+, via `vbiosOverrideArgs`), a registry value on Windows | Linux (desktop Blackwell / Ada tested), Windows | Same idea for board power as this project's boot-time edit, published first. | **NvpwrControl / NvpwrAIO** ([LevinAi-arch](https://github.com/LevinAi-arch/rtx-5070ti-laptop-160w-power-limit), [duanyunlun/NvpwrAIO](https://github.com/duanyunlun/NvpwrAIO); 2026-09) | Kernel-memory patching of the Windows driver's policy objects; later versions use a registry patch | Windows, RTX 50 laptop | Board power; closed source in later versions |

| **[Thermetery/Druta](https://github.com/Thermetery-Technology-Co-Limited/Druta)** (date not recorded; GPL-3.0) | Current-limit research and I²C regulator control | Windows, desktop | Its published field offsets for the same power-policy controls on other cards were used to cross-check this project's control layouts.
